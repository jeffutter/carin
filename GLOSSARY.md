# Glossary

**Artifact**
Something an Agent submits for a Reviewer to read and discuss.

**Kind**
The category an Artifact belongs to: markdown, html, image, or diagram. _(Definition still loose: the exact set and boundaries are undecided.)_

**Revision**
A version of an Artifact produced by an edit. _(Definition still loose: whether edits keep history is undecided.)_

**Comment**
A remark a Reviewer leaves on an Artifact for an Agent to read. _(Definition still loose: what a comment attaches to is undecided.)_

**Agent**
The automated party that submits, retrieves, edits and deletes Artifacts and reads Comments.

**Reviewer**
The human who views, lists, comments on and deletes Artifacts.
