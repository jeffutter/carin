A markdown Artifact can show an image or diagram Artifact with a `cairn:` reference in normal image syntax: `![alt](cairn:abc123)` for the latest Revision, or `![alt](cairn:abc123@2)` to pin one. Submit the image or diagram first, then reference its id. Local file paths are not uploaded. An embed naming a missing Artifact or Revision, or a markdown or html Artifact, is rejected with exit 4.
