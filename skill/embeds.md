To show an image or diagram Artifact inside markdown, submit that Artifact first. Then reference its id. Write `![alt](cairn:abc123)` for the latest Revision. Write `![alt](cairn:abc123@2)` to pin a Revision. Use `cairn:` references, because cairn does not upload local file paths. Exit 4 means the embed names a missing Artifact, a missing Revision, or a markdown or html Artifact.
