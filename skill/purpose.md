cairn stores Artifacts (documents, images, diagrams, html Bundles) so a human can review them in a web UI and comment on them. You submit an Artifact, the human reads it and leaves Comments in Threads, and you read those Comments and answer them by editing the Artifact. Every edit creates a new Revision; nothing is overwritten.

Inside an agent session (`AI_AGENT`, `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT` or `PI_CODING_AGENT` set) or whenever stdout is not a terminal, commands print JSON on stdout, except `get`, which prints raw content. To force JSON in another harness, pass `--json` or set `CAIRN_FORMAT=json`; `--text` or `CAIRN_FORMAT=text` forces human-readable text. Errors follow the same choice on stderr: a JSON object with a stable `code` and a `message`, and the exit code listed under "Exit codes". Run `cairn <command> --help` for the details of any command; the reference below lists every flag.
