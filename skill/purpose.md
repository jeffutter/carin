cairn stores Artifacts (documents, images, diagrams, html Bundles) so a human can review them in a web UI and comment on them. You submit an Artifact, the human reads it and leaves Comments in Threads, and you read those Comments and answer them by editing the Artifact. Every edit creates a new Revision; nothing is overwritten.

All commands print JSON on stdout (except `get`, which prints raw content). Errors print a JSON object with a stable `code` and a `message` on stderr and set the exit code listed under "Exit codes". Run `cairn <command> --help` for the details of any command; the reference below lists every flag.
