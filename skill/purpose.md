Use cairn to get a human's review of a document, image, diagram, or html page. Submit it as an Artifact. The human reads it in a web UI and writes Comments in Threads. Read the Comments and answer them by editing the Artifact. Each edit creates a new Revision.

Commands print JSON on stdout when any of `AI_AGENT`, `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT`, or `PI_CODING_AGENT` is set, or when stdout is not a terminal. `get` prints raw content instead. Pass `--json` or set `CAIRN_FORMAT=json` to force JSON. Pass `--text` or set `CAIRN_FORMAT=text` to force text. Errors on stderr follow the same format. JSON errors have a `code` and a `message`. Exit codes are listed under "Exit codes". Run `cairn <command> --help` for the flags of one command.
